# Skills

A Skill is a Markdown playbook inside a role ZIP. You start it from Claude’s Skills list in Cowork.

Typical Skills:

| Role | Skills |
|------|--------|
| BA | Jira Epic Analysis, Resume BA Work, BA Status |
| Architect | Plan Jira Epic, Materialize Work Package, Resume Architecture, Architecture Status |
| Developer | Implement Work Package, Resume Work Package, Developer Status, Claim Work Package |
| Quality | Review Work Package, Resume QA, Quality Status |

Skills call Runtime tools. They must not ask you for Make, `praxis` CLI, or `launchctl`.
